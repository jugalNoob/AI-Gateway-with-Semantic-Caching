# AI-Gateway-with-Semantic-Caching

A simple AI REST API project built using Node.js, Express.js, MongoDB, Redis, OpenAI and Embeddings.

## Features

* REST API
* AI Gateway
* MongoDB database
* Redis caching
* Semantic caching
* OpenAI API
* Embedding system
* React.js frontend
* Docker support

## Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Redis
* OpenAI
* Embeddings
* Docker
* Git & GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/jugalNoob/AI-Gateway-with-Semantic-Caching.git
```

Go to the project folder:

```bash
cd AI-Gateway-with-Semantic-Caching
```

Install dependencies:

```bash
npm install
```

## Environment Variables

Create a `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_url
REDIS_URL=your_redis_url
OPENAI_API_KEY=your_openai_api_key
```

## Run the Project

```bash
npm run dev
```

## Project Purpose

This project is built to practice and understand how to create an AI REST API using Node.js, Express.js, MongoDB and Redis.

It also uses embeddings and semantic caching to reuse responses for similar questions and reduce unnecessary AI API requests.
